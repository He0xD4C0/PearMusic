# Record Labels

Get information on record labels in the Apple Music Catalog.

## Topics

### Requesting Catalog Record Labels

[`Get a Catalog Record Label`](../applemusicapi/get-a-record-label.md)

Fetch a record label by using its identifier.

[`Get a Catalog Record Label’s Relationship View Directly by Name`](../applemusicapi/fetch-a-view-on-this-resource-by-name-5uhxd.md)

Fetch related resources for a single record label’s relationship view.

[`Get Multiple Record Labels`](../applemusicapi/get-multiple-record-labels.md)

Fetch one or more record labels by using their identifiers.

[`RecordLabels`](../applemusicapi/recordlabels.md)
