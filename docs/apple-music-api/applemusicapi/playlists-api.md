# Playlists

Get the contents of playlists, add new playlists to the user’s library, and add tracks to an existing playlist.

[`Get a Catalog Playlist’s Relationship View Directly by Name`](../applemusicapi/fetch-a-view-on-this-resource-by-name-6i3ek.md)

[`Get Multiple Catalog Playlists`](../applemusicapi/get-multiple-catalog-playlists.md)

Fetch one or more playlists by using their identifiers.

[`Get Charts Playlists by Storefront Value`](../applemusicapi/get-charts-playlists-by-storefront-value.md)

Fetch one or more Charts Playlists by using their Storefront value.
