# Artists

Get information about an artist, including the content they created and references to them in playlists and radio stations.

## Topics

### Requesting a Catalog Artist

[`Get a Catalog Artist`](../applemusicapi/get-a-catalog-artist.md)

Fetch an artist by using the artist’s identifier.

[`Get a Catalog Artist's Relationship Directly by Name`](../applemusicapi/fetch-a-relationship-on-this-resource-by-name-5akdm.md)

Fetch an artist’s relationship by using its identifier.

[`Get a Catalog Artist’s Relationship View Directly by Name`](../applemusicapi/fetch-a-view-on-this-resource-by-name-4kow5.md)

Fetch related resources for a single artist’s relationship view.

[`Get Multiple Catalog Artists`](../applemusicapi/get-multiple-catalog-artists.md)

Fetch one or more artists by using their identifiers.

### Requesting a Library Artist

[`Get a Library Artist`](../applemusicapi/get-a-library-artist.md)

Fetch a library artist by using its identifier.

[`Get a Library Artist's Relationship Directly by Name`](../applemusicapi/fetch-a-relationship-on-this-resource-by-name-9dsoc.md)

Fetch a library artist’s relationship by using its identifier.

[`Get Multiple Library Artists`](../applemusicapi/get-multiple-library-artists.md)

Fetch one or more library artists by using their identifiers.

[`Get All Library Artists`](../applemusicapi/get-all-library-artists.md)

Fetch all the library artists in alphabetical order.

### Handling the Response

[`Artists`](../applemusicapi/artists.md)

A resource object that represents the artist of an album where an artist can be one or more people.

[`ArtistsResponse`](../applemusicapi/artistsresponse.md)

The response to an artists request.

[`LibraryArtists`](../applemusicapi/libraryartists.md)

A resource object that represents an artist present in a user’s library.

[`LibraryArtistsResponse`](../applemusicapi/libraryartistsresponse.md)

The response to a library artists request.
